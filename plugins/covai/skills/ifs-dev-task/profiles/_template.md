## Branch rule
- pattern: topic/<USER>/<PREFIX>-<ID>-<Short-Description>
- USER: developer_short_name from .covai/workspace.md
- PREFIX: B = bug, M = CRIM or task, R = report
- ID: the work item ID
- Short-Description: work item title, words joined by hyphens, special characters removed,
  max about 60 characters
- base: always fetch first, then branch from origin/<base_branch>
