## Branch rule
- pattern: topic/<USER>/<PREFIX>-<ID>-<Short-Description>
- USER: developer_short_name of the developer running COVAI (from .covai/workspace.md),
  normally first 2 letters of first name + first 2 of last name, uppercase
  (Suresh Bandara -> SUBA). Never taken from the work item's assignee.
- PREFIX: B = bug, M = CRIM or task, R = report
- ID: the bug, CRIM or task ID in the portsmouthwater ADO
- Short-Description: work item title, words joined by hyphens, special characters removed,
  max about 60 characters
- base: always fetch first, then branch from origin/master
- example: topic/SUBA/B-21696-Survey-engine-not-firing
